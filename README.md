## Repository Purpose

This repository is designed as a **professional GitHub-based course** for learners, trainers, developers, and instructors who want to understand how jQuery still fits into modern web development.

The course does not teach jQuery as an outdated shortcut. Instead, it positions jQuery as a practical tool for:

- Maintaining and improving existing web systems
- Building interactive pages quickly
- Understanding DOM manipulation more clearly
- Comparing jQuery with modern Vanilla JavaScript
- Connecting UI behavior with AJAX, Fetch, REST APIs, JSON, PHP, and MySQL
- Creating real-world dashboard-style web applications

The course is suitable for Thai learners who want **clear explanations, practical examples, Thai inline comments, professional structure, and GitHub-ready learning materials**.

## jQuery and Modern JavaScript Mapping

This course intentionally compares jQuery with modern JavaScript.

Example:

```javascript
// jQuery
$("#employeeCard").addClass("active");

// Modern JavaScript
document.querySelector("#employeeCard").classList.add("active");
```

This helps learners understand both:

- What jQuery simplifies
- What the browser can already do natively
- How to maintain older systems while writing modern code

## Course Design Principles

- **Modernize before memorizing**: Learners should understand why a technique matters today.
- **Compare before replacing**: jQuery and Vanilla JavaScript are compared side by side.
- **Practice before theory overload**: Examples and labs support conceptual learning.
- **Readable code first**: Code should be understandable for learners and maintainers.
- **Thai comments for teaching**: Important code blocks include Thai inline comments for clarity.
- **Security by default**: Avoid unsafe HTML injection and careless rendering.
- **Accessibility matters**: Interactive UI should consider keyboard, labels, focus, and readable states.
- **Project-based learning**: The course ends with a realistic dashboard project.

## Final Note

This course is built to be practical, modern, and useful for real-world web development. jQuery remains valuable when used with clear judgment, especially for maintaining existing systems, teaching DOM concepts, and building focused interactive interfaces.

The goal is not to choose between jQuery and modern JavaScript. The goal is to understand both well enough to build, maintain, migrate, and teach interactive web applications professionally.
