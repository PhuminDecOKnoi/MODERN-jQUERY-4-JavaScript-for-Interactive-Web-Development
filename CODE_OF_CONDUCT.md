# Code of Conduct

## Our Commitment

We are committed to making this repository a welcoming, respectful, and professional learning space for everyone interested in JavaScript, jQuery, and interactive web development.

This project is intended for:

- students,
- teachers,
- trainers,
- developers,
- self-learners,
- HR / audit / dashboard builders,
- open-source contributors.

## Expected Behavior

Participants are expected to:

- use respectful and professional language,
- help others learn with patience,
- provide constructive feedback,
- focus criticism on code and content, not individuals,
- respect different experience levels,
- avoid misleading or unsafe technical advice,
- cite sources where appropriate.

## Unacceptable Behavior

Unacceptable behavior includes:

- harassment or intimidation,
- personal attacks,
- discriminatory language,
- sharing private information without permission,
- submitting malicious code,
- intentionally misleading learners,
- promoting unsafe security practices.

## Educational Standard

Because this repository is designed as a learning resource, contributors should avoid comments or examples that confuse learners unnecessarily.

When discussing alternatives, explain the reason clearly:

```text
Use .text() for plain text output because it avoids treating user input as HTML.
Use .html() only when the content is trusted and intentionally contains HTML.
```

## Enforcement

Maintainers may remove comments, issues, pull requests, or contributions that violate this Code of Conduct.

## Professional Tone

This repository follows a professional teaching tone:

- clear,
- practical,
- respectful,
- evidence-based,
- beginner-friendly,
- suitable for classroom and workplace learning.
