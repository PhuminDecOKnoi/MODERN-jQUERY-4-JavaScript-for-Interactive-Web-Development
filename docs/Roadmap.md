# Course Roadmap

**Project:** MODERN jQUERY 4 & JavaScript for Interactive Web Development  
**Version:** 1.0.0  
**Language:** Thai-first with English technical terminology  
**Audience:** Beginner to professional web developers

---

## 1. Roadmap Overview

This repository is developed as a complete learning path for modern interactive web development.

The course does not teach jQuery as an isolated legacy tool. Instead, it teaches jQuery 4 together with modern JavaScript so learners understand:

- how jQuery simplifies DOM operations,
- how modern browser APIs can replace many older jQuery patterns,
- when jQuery is still practical,
- how to maintain existing jQuery-based systems,
- how to build real-world interactive dashboards and CRUD applications.

---

## 2. Learning Phases

### Phase 1 — JavaScript and DOM Foundation

Learners build a strong base in JavaScript, DOM, events, functions, objects, arrays, and browser behavior.

Related modules:

- Module 01: JavaScript Fundamentals
- Module 03: DOM Selection and Manipulation
- Module 04: Events and Browser Interaction

### Phase 2 — jQuery 4 Core

Learners understand jQuery syntax, selectors, chaining, DOM traversal, attributes, properties, classes, and effects.

Related modules:

- Module 02: Why jQuery Still Matters
- Module 05: jQuery Selectors
- Module 06: DOM Traversal
- Module 07: DOM Manipulation
- Module 08: CSS, Classes, and Effects

### Phase 3 — Events, Forms, and User Interaction

Learners build practical UI behavior using event delegation, forms, validation, and dynamic feedback.

Related modules:

- Module 09: Events and Event Delegation
- Module 10: Forms and Validation
- Module 11: UI Patterns and Components

### Phase 4 — AJAX, Fetch, JSON, and REST API

Learners connect frontend interfaces to backend data sources.

Related modules:

- Module 12: AJAX with jQuery
- Module 13: Modern Fetch API
- Module 14: JSON and REST API
- Module 15: Error Handling and Loading States

### Phase 5 — Professional Integration

Learners connect jQuery and JavaScript with PHP, MySQL, Bootstrap, plugins, and dashboard patterns.

Related modules:

- Module 16: jQuery Plugins
- Module 17: jQuery 3 to 4 Migration
- Module 18: jQuery with PHP and MySQL
- Module 19: Security, Performance, and Accessibility

### Phase 6 — Capstone Project

Learners complete a real-world dashboard project.

Related module:

- Module 20: Interactive Audit / HR Dashboard Capstone

```text

Week 04: Forms, Validation, and UI Patterns
Week 05: AJAX, Fetch, JSON, and REST API
Week 06: Plugins, Migration, and Best Practices
Week 07: Dashboard Project Development
Week 08: Capstone Presentation and Review
```

---

## 5. Final Capability Target

After completing this course, learners should be able to:

- read and maintain existing jQuery code,
- write modern jQuery 4 code safely,
- translate jQuery patterns into vanilla JavaScript,
- build interactive forms and dashboards,
- use AJAX and Fetch API for data exchange,
- integrate frontend behavior with REST APIs,
- understand security and performance risks,
- deliver a complete interactive web project on GitHub.
